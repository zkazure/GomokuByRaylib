#+TITLE: Gomoku By Raylib

write Gomoku with Raylib.

* Get Started

#+begin_src sh
mkdir -p build
bear --output build/compile_commands.json -- make
#+end_src

* Rule

- board
  + 15x15
  + stones are placed on the intersections.
- black first
- five stones in a continuous horizontal, vertical, or diagonal line wins.

* Design

** Type
- GameState
  + initial
  + playing
  + gameover
- PieceType:
  + empty
  + black
  + white
- Coordinate = pair<int, int>

** GlobalGame

泛指这个游戏相关的状态。

- screenLayout (default Vector2(800, 600))
- GameState
- boardBackground: 棋盘的背景颜色

** Player

玩家，用来区分黑白棋手，同时在网络对战中也可以区分不同的棋手。

- id
- name
- playing: 持有的棋子类型

** LocalGame

特指棋盘的设置、落子状态以及操作历史。

- boardSize (default 15): standard board is 15 x 15.
  which determines how many rows and columns.
- boardState：棋盘上棋子的分布 (row, col).
- moveHistory


- Make1Move: 改变 boardState、moveHistory.
** Object

Everything which is visible in game is an ~object~.

- position: the middle of object

*** Board

- globalGame: 全局游戏的设置
- localGame: 本局棋局的设置
- ratio (default 3/4): 相对于获取的 windowLayout，这个 board 比例。
- width: 根据所在的 window 大小决定实际棋盘显示的宽度。
- cellWidth: 根据 width, size 计算得到每一格的宽度。
- leftTop: 棋盘左上方点的坐标
- intersections: 棋盘上每一个交点的坐标。外围一圈是距离无限大的。
  [1-boardSize] 为实际的可落子区域
- pieces: 实际棋子


- pos2coor: convert position on screen to coordinate on the board.
- coor2pos
- createPiece: 同时调用 localGame->make1Move


*** Piece

泛指棋盘上的所有物体，后续可以拓展。

- board: 棋盘，可能需要棋盘的一些状态
- type: nil, black, white
- ratio: 棋子半径相对于棋盘单格的比例
- radius

**** 可能的派生

- Stone：棋子
